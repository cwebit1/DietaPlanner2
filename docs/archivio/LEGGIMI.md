# [STORICO] Archivio documentazione

I file in questa cartella sono **storici e non operativi**: non vanno usati come fonte di regole correnti, anche se nel testo conservano formule come «leggere per primo», «vincolante» o «dominante». Sono conservati integralmente (spostati con `git mv`, cronologia git intatta) per non perdere nulla.

Se un altro documento li cita come `docs/<nome>.md`, il file ora si trova in `docs/archivio/<nome>.md`.
